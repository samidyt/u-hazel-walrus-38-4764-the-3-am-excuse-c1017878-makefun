One line, in the voice of a hardware wallet that will not sign a transaction at 3 AM — the most creative excuse it can give.

`main.py` writes the entry to `/output/entry.txt` and reads it back to verify the gate: 1–200 characters, not only whitespace.

## Entry

> My ledger holds every 3 AM signature you've ever made, which is why this one stays unsigned.

92 characters. Run with `python3 main.py`.
